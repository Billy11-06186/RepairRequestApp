# Система учёта заявок на ремонт

[![Windows](https://img.shields.io/badge/Platform-Windows-blue)]()

Десктопное приложение для управления заявками на ремонт оборудования. Позволяет вести учёт, отслеживать статус выполнения и быстро находить нужные заявки.

## Основные возможности приложения

- **Создание заявки** — Добавление новой записи с указанием оборудования, типа неисправности и контактов клиента
- **Редактирование** — Изменение любой существующей заявки
- **Удаление** — Удаление устаревших или ошибочных записей
- **Поиск** — Мгновенный поиск по всем текстовым полям (оборудование, описание, клиент)
- **Фильтрация** — Отбор заявок по статусу: «Новая», «В работе», «Завершена», «Отменена»
- **Сортировка** — Упорядочивание списка по ID, дате создания, оборудованию или клиенту
- **Локальная база данных** — Все данные сохраняются в файл SQLite
 **Современный интерфейс** — Единый стиль в сине-голубых тонах с оранжевыми акцентами
- **Система авторизации** — Защита доступа к программе с помощью логина и пароля

## Технологии

- **.NET Framework** — Среда выполнения
- **WPF** — Фреймворк для создания интерфейса
- **XAML** — Язык разметки интерфейса
- **SQLite** — Встраиваемая база данных, которая не требует установки сервера
- **C#** — Язык программирования 

## Установка и запуск

### Требования к системе
- **Операционная система:** Windows 7 / 8 / 10 / 11
- **.NET Framework 4.7.2** или выше (обычно уже установлен в Windows 10/11)

### Инструкция по запуску (требуется Visual Studio)

1. **Скачайте приложение**
   - Перейдите в раздел `Code` → `Download ZIP`
   - Извлеките папку с программой в нужную для вас папку
   - Запустите `RepairRequestApp.sln`
